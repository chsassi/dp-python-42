# Discovery Piscine Python (42 School)

🇬🇧🇺🇸
This repository contains exercises and projects developed during the Python Discovery Piscine at 42 School in Florence. 
The goal of this program is to provide a solid introduction to the Python programming language through a series of practical and theoretical challenges.

🇮🇹
Questa repository contiene esercizi e progetti sviluppati durante la Discovery Piscine di Python alla Scuola 42 di Firenze. 
L'obiettivo di questa settimana di "piscine" è fornire una solida introduzione al linguaggio di programmazione Python attraverso una serie di sfide pratiche e teoriche.
